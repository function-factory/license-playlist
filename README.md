# License Playlist

IT·디자인·마케팅·AI 분야의 자격증 정보를 한곳에서 탐색하는 React 기반 웹 앱입니다. 자격증을 분야별로 둘러보고, 준비 기간·난이도·응시료·시험 구성·공식 링크를 한 화면에서 확인할 수 있도록 구성했습니다.

## 주요 기능

- 분야별 자격증 탐색: IT, 디자인, 마케팅, AI
- 자격증 카드에서 준비 기간, 합격률, 난이도, 응시료 요약
- 상세 화면에서 시험 기준, 학습 팁, 활용 사례, 공식 자료 링크 확인
- 자격증 검색 및 분야 필터
- 반응형 레이아웃

## 기술 스택

- React 19
- Vite 8
- Vanilla CSS
- Oxlint

## 시작하기

```bash
npm install
npm run dev
```

개발 서버는 기본적으로 `http://localhost:5173`에서 실행됩니다.

## 검증

```bash
npm run lint
npm run build
```

## 프로젝트 구조

```text
src/
├── App.jsx       # 화면 구성과 자격증 데이터
├── App.css       # 컴포넌트 및 레이아웃 스타일
├── index.css     # 전역 스타일과 디자인 토큰
└── main.jsx      # React 진입점
public/           # 정적 리소스
```

## 데이터 안내

시험 일정, 응시료, 합격률 등은 변경될 수 있으므로 실제 응시 전 반드시 각 자격 운영기관의 공식 공지를 확인하세요. 앱에 포함된 외부 링크는 공식 사이트 탐색을 위한 참고용입니다.
